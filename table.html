Comandos básicos de HTML
Comando Explicación
<html> Indica el inicio del documento HTML.
<head> Contiene información sobre la página web.
<title> Define el título que aparece en la pestaña del navegador.
<body> Contiene el contenido visible de la página.
<h1> - <h6> Crean encabezados de distintos niveles, desde el más importante (h1) hasta el menos importante (h6).
<p> Crea un párrafo de texto.
<br> Introduce un salto de línea.
<hr> Inserta una separación temática, normalmente representada por una línea horizontal.
<b> Muestra el texto en negrita sin indicar necesariamente su importancia.
<strong> Indica que el texto tiene especial importancia, normalmente mostrándolo en negrita.
<i> Muestra el texto en cursiva.
<u> Subraya el texto.
<a href=""> Crea un enlace a otra página o recurso.
<img src="" alt=""> Inserta una imagen. src indica su ubicación y alt proporciona un texto alternativo.
<ul> Crea una lista desordenada con viñetas.
<ol> Crea una lista ordenada con números o letras.
<li> Define un elemento de una lista.
<table> Crea una tabla.
<tr> Crea una fila de una tabla.
<th> Crea una celda de encabezado de una tabla.
<td> Crea una celda normal de una tabla.
<div> Agrupa elementos para organizarlos o aplicarles estilos.
<span> Agrupa una parte pequeña del texto para aplicarle estilos o identificarla.
<form> Crea un formulario para recoger información del usuario.
<input> Permite introducir datos, como texto, contraseñas o casillas de selección.
<button> Crea un botón interactivo.
<link> Permite enlazar recursos externos, como una hoja de estilos CSS.
<style> Permite escribir reglas CSS dentro del documento HTML.
<script> Permite incluir o enlazar código JavaScript.
